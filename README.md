# Sabarin Laser Tech - Business Website

A professional, responsive website for **Sabarin Laser Tech**, a laser cutting and metal fabrication business based in Trichy, Tamil Nadu. This project showcases modern web development practices with full SEO optimization for local business visibility.

## 📋 Project Overview

This website serves as the digital presence for Sabarin Laser Tech, featuring:
- **Services Portfolio**: Laser cutting, SS/MS gates, railings, shed works, and metal signage
- **Works Gallery**: Filterable portfolio showcasing completed projects
- **Contact System**: WhatsApp-integrated contact form for instant customer inquiries
- **SEO Optimized**: Full search engine optimization for Google visibility
- **Mobile Responsive**: Optimized for all devices (desktop, tablet, mobile)

## 🚀 Features

### 1. **Homepage (index.html)**
- Hero section with company introduction
- About section (Tamil & English)
- Video portfolio carousel with 7 project videos
- Services grid with hover effects
- Call-to-action buttons

### 2. **Works Page (work.html)**
- Category-based filtering (Laser, Gates, Railings, Sheds, Letters)
- Responsive grid layout (3 columns → 2 → 1 based on screen size)
- Hover overlays with project details
- Smooth animations on filter change

### 3. **Contact Page (contact.html)**
- Detailed contact form with service selection
- WhatsApp integration for instant messaging
- Business information display
- Animated logo section
- Quick contact buttons (Call, WhatsApp, SMS)

### 4. **SEO Optimization**
- **Meta Tags**: Title, description, keywords for each page
- **Open Graph**: Social media preview optimization
- **Schema.org**: Structured data for Google Business
- **Sitemap**: XML sitemap for search engines
- **Robots.txt**: Crawler instructions
- **Image Alt Tags**: Descriptive alt text for accessibility and SEO

## 📱 Responsive Design

The website is fully responsive with breakpoints at:
- **Desktop**: 1024px and above (3-column grid)
- **Tablet**: 769px - 1024px (2-column grid)
- **Mobile**: Below 768px (1-column grid, optimized navigation)
